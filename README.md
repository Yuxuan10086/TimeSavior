# TimeSavior

个人网络访问管控：浏览器流量经本地 HTTPS MITM 代理，对哔哩哔哩 / 知乎 / 抖音做推荐流屏蔽、连续娱乐监控与每日自由时段；Clash 仅作上游翻墙服务。

## 与 Clash 共存

1. Clash：**关闭「系统代理」与 TUN**，保留端口 `7890`
2. TimeSavior：占用系统代理 `127.0.0.1:18888`，放行流量时串联 Clash
3. 开关 Clash 只影响上游，不影响管控

## 你只需要做这一步

```powershell
cd C:\path\to\timeSavior
.\scripts\install.ps1
```

脚本会自动：编译 → 信任 CA → 写开机启动 → 启动程序，并自检推荐流拦截（HTTP 403）。  
以后更新也跑同一条命令即可（幂等）。

退出/解锁默认密码：`timesavior`  
Clash：保持「系统代理」关、「TUN」关，端口 `7890`。

## 功能对照

| 能力 | 说明 |
|------|------|
| SoftBlock | 拦推荐流，放行搜索与内容页 |
| FullBlock | 连续娱乐达阈值后整站临时屏蔽 |
| Feed unlock | 每天 21:30–次日 04:00 内首次打开推荐页起 30 分钟 |
| Clash 上游 | 端口探测，存活走 Clash，否则直连 |
| 反关闭 | 代理写回、退出密码+冷却、watchdog 拉起 |

## 界面设计原则（宪法）

本仓库遵循下列原则。原则本身面向通用工具产品后台、设置页与控制台，可直接迁移到其他项目。

**视觉基调**：浅色、克制、居中的产品感；同一产品内页面视觉语言统一。拒绝调试面板感、工业深色炫技，以及为「看起来专业」而堆砌的装饰。

**展示**：只呈现用户决策与操作所需的信息——当前状态、可执行动作、关键结果与必要告警。信息按任务分组，让结构本身说明关系。

**不展示**：开发者备注、设计口径、内部口号、原始日志 / 事件载荷、技术链接堆砌，以及说教式「怎么用 / 为什么这样设计」文案。用户应通过布局与操作理解产品，而不是读说明书。

**文案**：能通过界面结构与控件表达的，不要写成解释句；用词短、准、可操作。
